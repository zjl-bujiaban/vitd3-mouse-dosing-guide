# 小鼠VitD3与Remodelin给药核对及计算器

## 打开在线网页

**[点击进入：VitD3与Remodelin小鼠给药计算器](https://zjl-bujiaban.github.io/vitd3-mouse-dosing-guide/)**

电脑和手机浏览器均可直接访问，无需登录GitHub或申请访问权限。

网页包含VitD3配制记录、按体重换算的给药计算器、Remodelin配制记录及相关研究资料。

## 从GitHub打开

1. 在本项目首页点击上方的在线网页链接。
2. 也可以点击右侧About中的网站链接。
3. 仓库所有者还可通过Settings → Pages → Visit site进入。

`index.html`是网页源代码；点击该文件会查看代码，使用上面的在线链接即可进入计算器。

## 下载项目

在项目首页选择Code → Download ZIP，可下载完整项目。
